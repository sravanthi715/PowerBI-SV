# PowerBI-SV

Power BI Projects for financial analysis and reporting.

## Credit Defaulters Analysis

A comprehensive Power BI report to analyze credit defaulter patterns across multiple dimensions.

### Key Dimensions
- Gender, Age, Education, State, Marital Status

### Visualizations
- Stacked bar charts
- Maps
- Line charts
- Slicers
- Clustered column charts

### DAX Functions
- DIVIDE
- SUM
- COUNT
