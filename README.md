# PowerBI-SV
Power BI Projects

### Car Insurance Project Overview

This Car Insurance Data Analytics provides comprehensive analysis and visualization of car insurance data. The interactive dashboard delivers actionable insights into insurance claims, claim frequency, risk assessment, customer demographics to support data-driven decision-making.

### Key Metrics & KPIs

- Total Claims Value
- Number of Claims
- Average Car Age
- Average Claim Frequency
- Average Travel Time
- Average Customer Age
- Average Home Value
- Average Income

### Car Insurance Dashboard Overview

The dashboard includes multiple interactive visualizations:
- Claims Summary and Trends by Age Group
- Claims Summary by Car Type and Car use
- Claims percentage by Income Group
- Claims percenage by Occupation
- Claims Percentage by Education Level
- Gand Total Percentage by Marital Status and Urban City
- Decompositon Tree with respect to Education, Occupation, Age, Gender, Car Type, and Car Use
